# Documentação Situação de Aprendizagem 2 Somativa JavaScript

NÍVEL FÁCIL - LÂMPADA

    -Funcionalidades:
        -Acender e desligar a lâmpada;
        -Depois de 2 clicks quebrar a lâmpada;
        -Trocar a lâmpada após quebrar.

    -Desafios:
        -Fazer o botão e a função de trocar a lâmpada;
        -Deixar estéticamente bonito;


NÍVEL MÉDIO - SEMÁFORO

    -Funcionalidades:
        -Mudar de cor a cada 2 segundos.

    -Desafios: 
        - Não está achando o index.html (Can not get index.html);
        - Troca das cores;

NÍVEL DIFÍCIL - PEDRA/PAPEL/TESOURA

    -Funcionalidades:
        - Jogador (usuário) joga contra a máquina;
        - Ele escolhe 1 entre os 3 elementos (pedra, papel e tesoura);
        - A máquina escolhe aleatóriamente 1 dos elementos também.
        - Se os dois escolheram o mesmo dá empate;
        - Se escolheram diferente segue a ordem de hierarquia de vitória.

    -Desafios:
        - Fazer a máquina escolher por si só (random);
        - Definir a hierarquia de vitória (qual elemento vence de outro)
